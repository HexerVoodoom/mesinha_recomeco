Política de Privacidade do Mesinha

Última atualização: 16 de junho de 2026

Mesinha é um aplicativo privado para uso pessoal de um casal, criado para organizar listas, lembretes e um mural de memórias compartilhadas. Esta página explica quais dados o app armazena e como eles são tratados.

Quais dados são armazenados

  • Conteúdo que você adiciona no app: títulos, comentários, datas, tags, lembretes e itens de listas;
  • Fotos, vídeos e áudios enviados ao mural, e o nome de quem criou cada item;
  • Preferências do app, como nome do casal e cor do tema.

O Mesinha não exige cadastro com e-mail, telefone ou documentos. O acesso é feito por dois perfis fixos (definidos pelos próprios usuários), sem coleta de dados de identificação pessoal além do que é digitado manualmente dentro do app.

Onde os dados ficam armazenados

Os dados são armazenados em um banco de dados gerenciado pela Supabase e o aplicativo é hospedado via Cloudflare Pages. Não compartilhamos, vendemos ou usamos esses dados para publicidade. Os dados são acessíveis apenas pelas pessoas que têm o link e os perfis do app.

Permissões do app

O app pode solicitar acesso à câmera, microfone e galeria de fotos apenas quando você escolhe adicionar uma foto, vídeo ou áudio ao mural. Pode também solicitar permissão de notificações para avisos de lembretes. Nenhuma dessas permissões é usada para rastreamento.

Compartilhamento com terceiros

Não compartilhamos dados com terceiros. O app não usa ferramentas de analytics, publicidade ou rastreamento de comportamento.

Exclusão de dados
